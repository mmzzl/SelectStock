2、【A/C验收条件】 - 开发者（待填写）

- 私有数据接口清单全覆盖：渠道 CRUD、站内信列表/已读、历史/明细、改密/me 均按当前身份过滤。
- system 运行、订阅策略：全员可见 / 按全局语义（策略修改全局权限 + 审计）。
- 越权响应：无权限 404/403 语义，不泄露资源存在性；owner 由服务端生成、客户端开放字段不信任。
- 归属校验在 service 层强制，客户端不可绕过（非前端控制）。
- 非功能：过滤为查询复合条件命中索引，p95 ≤1s（PERF-02）；遗留过滤点 → code review 死线。
- 验收：A/B 两账号遍历 B 用 A 的资源 id 请求全部按用户接口 → 100% 拒绝。
