# Tech-服务级-token刷新与请求拦截.md

1、【技术故事】 - 开发者（待填写）

系统级 Tech：Tech-系统级-统一认证与会话（Story3.2.1 / REQ-011）。
职责：客户端请求拦截与令牌管理：access token 存本地（不明文敏感日志）、refresh 自动续期、401 统一拦截并单次重放、刷新失败回登录；登出清 token。

2、【A/C验收条件】 - 开发者（待填写）

- 业务请求 401 → 自动 refresh → 重放原请求（≤1 次）用户无感。
- refresh 失败/拒绝 → 清 token 回登录页。
- token 不写日志、不明文存储（SEC-07）；登出调用登出接口 + 本地清 token。
- 并发 401 只触发一次 refresh（排队重放）。
- 非功能：拦截封装单点可复用（所有业务页统一走）。
- 验收：token 过期 → 自动续期重放成功；refresh 失败 → 回登录。

3、【依赖与风险】 - 开发者（待填写）

- 依赖：后端 auth（refresh 机制复用）。
- 风险：并发 401 风暴（低）→refresh 排队单次。
