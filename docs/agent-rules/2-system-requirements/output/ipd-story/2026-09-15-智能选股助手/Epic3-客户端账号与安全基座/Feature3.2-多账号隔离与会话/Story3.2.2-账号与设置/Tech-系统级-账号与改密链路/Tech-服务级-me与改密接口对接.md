# Tech-服务级-me与改密接口对接.md

1、【技术故事】 - 开发者（待填写）

系统级 Tech：Tech-系统级-账号与改密链路（Story3.2.2 / REQ-013）。
职责：客户端账号页对接 `GET/PUT /api/v1/auth/me`（账号信息展示）与 `POST /api/v1/auth/change-password`（改密）；沿用后端复杂度/历史防重用校验、错误文案原样透传；登出清 token。

2、【A/C验收条件】 - 开发者（待填写）

- me 展示用户名/显示名/邮箱与接口一致（可编辑字段视后端支持）。
- 改密表单：旧/新/确认三字段掩码必填；两次不一致本地即时提示"两次输入的新密码不一致"；提交期间按钮禁用。
- 错误信息原样透传，无二次猜测；到期遵循 password_expired/expire_warning。
- 登出：调用登出接口 + 本地清 token，业务页不可再访问。
- 非功能：me/改密往返 ≤2s（p95）；新密码不明文落日志（SEC-07）。
- 验收：改密成功/策略拒绝/旧密码错误/两次不一致各态文案正确。

- 依赖：REQ-011 认证、后端 auth API。
- 风险：策略文案一致性（低）→原样透传。
