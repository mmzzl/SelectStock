## 【Feature】Feature3.1-响应式导航外壳

【关联关键价值点】⭐

支撑 Epic3"响应式外壳承载全业务"价值：一套 UniApp 代码编译 H5 + App，手机底部 4 Tab、PC 侧栏 + 顶栏，路由守卫统一会话入口，为选股/结果/消息/设置提供统一宿主（对应 ch02 场景2/3 外壳）。

【特性需求分类】⭐

基本可用——应用外壳是所有页面的承载骨架，缺失则产品不可使用。

【功能级 Playbook】⭐

1、手机形态场景：打开 App → 底部 4 Tab（选股/结果/消息/设置）→ 切换 Tab 各页正常加载，消息 Tab 徽标显示未读数。
2、PC 形态场景：宽屏浏览器（≥768px）→ 左侧栏 + 顶栏（页面标题 + 用户信息）→ 4 Tab 可达。
3、路由守卫场景：未登录访问业务路由 → 重定向登录页；已登录访问登录页 → 直达首页；登录页/版本检查等公开路由不受守卫拦截。

【场景建模】🔲

不涉及（场景简单，无三级分解必要）。

【关键交互说明】🔲

- 断点 768px（<768px 底部 Tab，≥768px 侧栏 + 顶栏；=768px 按宽屏渲染）。
- 消息未读 100+ 显示"99+"，不溢出。

【特性验收条件】⭐

1. 断点切换正确，4 Tab 全可达，未登录重定向登录页（REQ-012 验收）。
2. 高频 Tab 加载 p99 ≤3s、无 ≥7s 页面（PERF-01）。
3. 兼容 Chrome80+/Edge79+/Safari13.1+/Firefox72+（COM-02）。
4. 页面组件双形态复用、内容一致。

【非功能需求约束 DFX】⭐

QS-004 要求 DFX 需求基线全量落地，不满足项有 Story 跟踪。

- 性能：高频 Tab 加载 p99 ≤3s、无 ≥7s 页面（PERF-01，Story3.1.1）
- 安全性：路由守卫强制登录态（SEC-02，Story3.1.1）
- 可测试性：断点矩阵 375/768/1024/1440px 自动化断言（TES-01 测试工具表，Story3.1.1）
- 兼容性：浏览器兼容矩阵（COM-02，Story3.1.1）；移动端底部 Tab 触控适配（COM-03）
- 可运维性：登录态承载（ch06 §6.3）
- 其他：非 XAAS，客户成功维度不涉及（QS-008 裁剪）
