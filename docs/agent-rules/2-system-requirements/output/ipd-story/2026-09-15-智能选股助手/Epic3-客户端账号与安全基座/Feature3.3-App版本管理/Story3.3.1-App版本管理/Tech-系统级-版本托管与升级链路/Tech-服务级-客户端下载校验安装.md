2、【A/C验收条件】 - 开发者（待填写）

- 版本检查：启动/回前台触发；本地 version_code < 最新 → 弹"发现新版本"。
- force=false：可"以后再说"跳过；force=true：弹窗不可关闭，升级完成前不可进入主界面。
- Android：下载进度条 → 校验 MD5 = 声明 md5 → 引导"安装未知应用"授权 → 调系统安装；MD5 不一致 → 拒绝安装、删除残留、"安装包校验失败，请重新下载"。
- 下载中断 → 可重试；version_code 数值比较防降级（本地更高不强制降级）。
- H5（PC）：新版本仅顶部提示"有新版本，请刷新"；版本接口不可达 → 静默放行。
- 非功能：Android 授权引导（COM-04）；可配置 mock（force 0/1、status enabled/disabled）供模拟器验证（TES-05）。
- 验收：force=0 跳过下次再提示；force=1 弹窗不可关；MD5 错误拒绝安装。
