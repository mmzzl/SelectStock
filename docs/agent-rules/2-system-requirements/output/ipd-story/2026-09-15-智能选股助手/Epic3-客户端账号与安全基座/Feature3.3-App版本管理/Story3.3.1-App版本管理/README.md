### 【Story】Story3.3.1-App版本管理 🔴

> 来源：REQ-014（P0）

【用户故事】⭐

作为个人投资者（使用者本人），我想要 App 启动时自动检查版本并支持可选/强制升级，以便新功能与修复及时到达手机，无需人工拷贝安装包。

【场景说明】⭐

针对版本升级场景：`GET /api/v1/app/version` 检查最新发布版本；以 version_code（数值）比较新旧；force=false 可跳过、force=true 不可跳过；Android 整包下载（进度条）/MD5 校验/授权安装；H5 仅提示刷新。
**痛点背景**：新版本需人工拷贝安装包到手机，升级成本高；诉求=自动化检查/下载/校验/安装。
- 来源：REQ-014（关联 ch02 场景4）

---

【A/C 验收条件】

一、功能性验收条件 ⭐

1、业务规则：
- 版本检查：`GET /api/v1/app/version` 返回最新发布版本（version_code/version_name/platform/force/url/md5/size_bytes/release_notes/released_at/status）。
- 比较：以 version_code（数值）判断新旧，不以 version_name 文本。
- 更新策略：force=false 可"以后再说"跳过；force=true 不可跳过，完成升级前不可进入主界面。
- Android 下载安装：uni.downloadFile（进度条）→ 校验 MD5 = url 声明的 md5 → 引导"安装未知应用"授权 → 调系统安装。
- H5（PC）：检测到新版本仅顶部提示"有新版本，请刷新"，无下载安装。
- 发布管理：版本记录 status=enabled/disabled，disabled 不进入提示；仅返回 enabled 的最新版。

2、实例化场景描述：

   正常场景：可选更新 + 下载安装成功
   Given（前提条件）：新版 force=false，本地 version_code < 最新
   When（行为）：启动检查 → 点击"立即升级" → 下载完成
   Then（结果）：弹"发现新版本"；下载进度条走完 → MD5 校验通过 → 引导授权 → 系统安装 → 新版启动；点"以后再说"关闭提示下次再提示

   异常场景：MD5 不一致
   Given（前提条件）：下载包哈希与声明不符
   When（行为）：安装前校验
   Then（结果）：拒绝安装并删除残留，提示"安装包校验失败，请重新下载"

   异常场景：下载中断
   Given（前提条件）：网络中断
   When（行为）：下载
   Then（结果）：提示失败可重试（断点续传不承诺，重下允许）

   安全场景：强制更新
   Given（前提条件）：新版 force=true
   When（行为）：启动检查命中
   Then（结果）：弹窗不可关闭，完成升级前无法进入主界面

   安全场景：版本比较
   Given（前提条件）：version_name 相同但 version_code 更高
   When（行为）：检查
   Then（结果）：以 version_code 判定为新版并提示

   边界场景：无更新 / 版本接口不可达
   Given（前提条件）：本地已是最新/无 enabled 记录；或后端暂不可达
   When（行为）：检查
   Then（结果）：无弹窗正常进入；静默放行（不阻塞使用），不报错

【操作步骤】⭐

1. App 启动/回前台 → 自动版本检查。
2. 命中新版：可选更新弹"发现新版本"（以后再说/立即升级）；强制更新弹窗不可跳过关机即可关闭后使用。
3. 点"立即升级" → 下载 APK（进度条）→ MD5 校验 → 引导"安装未知应用"授权 → 系统安装 → 新版启动。
4. H5（PC）：顶部提示"有新版本，请刷新"，手动刷新。

【期望效果】⭐

version_code 数值比较正确；force 策略生效；MD5 校验后安装；H5 仅提示刷新；版本检查 p95 ≤1s（PERF-02 子集）。

【需求规格约束】🔲

版本升级弹窗交互稿（待交互设计阶段产出）。

二、非功能性验收条件 ⭐

【产品需求】

- 性能：版本检查接口 p95 ≤1s；下载展示进度。
- 兼容性：Android"安装未知应用"授权引导（COM-04）；H5 浏览器矩阵（COM-02）。
- 可测试性：测试 APK + 版本记录可配置（force 0/1、status enabled/disabled），模拟器验证下载/校验/安装（TES-05）。

【安全需求】⭐ 必填（QS-007）

- 下载后校验 MD5，不一致拒绝安装并删除残留（SEC-04）。
- APK URL 由后端托管目录生成，防任意路径。
- version_code 比较逻辑防降级攻击（本地版本 > 服务器版本不强制降级）。

【海外合规】🔲

不涉及（个人自用国内工具，QS-006 裁剪）。

【依赖与风险】⭐

1、需求关联性，内部功能依赖：后端版本记录 + 托管目录 + `GET /api/v1/app/version`；强制更新影响后续可用性策略。
2、技术风险、测试风险：Android 授权/安装差异（中）→引导授权 + MD5 校验（TR1 §1.3.5 已评估）。
3、跨团队协作（沟通/确认/附件）：Android 系统安装流程（产物为 APK，非本系统代码）。
