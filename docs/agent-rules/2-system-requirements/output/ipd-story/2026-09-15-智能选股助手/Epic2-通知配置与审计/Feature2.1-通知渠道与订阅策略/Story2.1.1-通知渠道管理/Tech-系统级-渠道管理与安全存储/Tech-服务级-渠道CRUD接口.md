系统级 Tech：Tech-系统级-渠道管理与安全存储（Story2.1.1 / REQ-006）。
职责：后端通知渠道 CRUD 接口（企微/钉钉/飞书/邮箱）：字段校验、密钥 AES-GCM 加密落盘（不明文返回）、user_id 强制隔离、删除二次确认由客户端承载。

2、【A/C验收条件】 - 开发者（待填写）

- 字段校验：名称 1~50 字符；类型枚举（默认 wecom）；webhook 必须合法 http(s) URL；密钥 ≤200、脱敏、不回显明文。
- 所有操作仅作用于当前用户（user_id 隔离）；B 操作 A 的渠道 → 无权限语义。
- 删除接口触发删除（确认弹窗在客户端）；启用/停用状态字段可维护。
- 渠道写操作写审计（REQ-017）。
- 非功能：CRUD/查询 p95 ≤1s（PERF-02）；加密存储（SEC-03）。
- 验收：新增企微渠道 → 保存成功、密钥加密落库、列表仅本人可见；B 查询 A → 无权限。

3、【依赖与风险】 - 开发者（待填写）

- 依赖：REQ-011 认证、REQ-017 审计、notify 发送器。
- 风险：密钥外泄（低）→AES-GCM + 不明文返回已覆盖。
