2、【A/C验收条件】 - 开发者（待填写）

- 测试发送仅作用于当前用户自己的渠道。
- 成功 → 反馈"送达成功"；失败 → 反馈可读原因（如"发送失败：xxx"）。
- 测试发送不改变渠道配置；复用 notify 发送器。
- 非功能：测试发送异步（不阻塞页面）；结果可追溯（日志）。
- 验收：webhook 指向 mock 端点 → mock 收到正确 payload、界面反馈与发送结果一致；mock 下线 → 可读失败原因。
