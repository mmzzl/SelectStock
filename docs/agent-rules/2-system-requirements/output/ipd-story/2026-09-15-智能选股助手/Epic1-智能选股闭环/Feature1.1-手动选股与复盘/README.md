## 【Feature】Feature1.1-手动选股与复盘

【关联关键价值点】⭐

支撑 Epic1"手动选股 + 结果沉淀 + 信号送达"价值：任意时刻勾选策略立即发起选股（≤2s 返回 run_id），任务异步执行、状态可视，成果进入结果沉淀闭环，可随时复盘。

【特性需求分类】⭐

基本可用——手动选股是用户主动触发选股的核心操作入口，缺失则产品价值闭环不可用（对应 ch02 场景2）。

【功能级 Playbook】⭐

1、临时决策场景：打开选股 Tab → 勾选 1 个或多个策略（≤3 步）→ 点击"立即选股" → ≤2s 获得 run_id，任务异步执行 → 完成后结果 Tab 展示该次命中明细（manual 归属本人，仅本人可见）。
2、治理兜底场景：提交时已有运行中任务 → 拒绝并提示"已有选股任务执行中，请稍后再试"；任务超 30 分钟置 failed；插件失败重试 3 次后置 failed 并通知。

【场景建模】🔲

不涉及（场景已在 ch02 场景2 完整描述，层级简单无需三级分解）。

【关键交互说明】🔲

- 勾选策略数量 ≥1 才能发起选股（空策略提交返回 400"请至少勾选一个策略"）。
- 已有运行中任务提交被拒并提示；超时/失败任务在结果 Tab 展示失败原因。

【特性验收条件】⭐

1. 策略列表从插件实时获取并可勾选，提交 ≤2s（p95）返回 run_id（PERF-03）。
2. 任务执行状态 running→success/failed 可查询；同一时刻全局仅 1 个运行中任务（SCA-02）。
3. 插件失败自动重试 3 次（指数退避）后置 failed 并触发 select_failed 通知（REL-02 / REQ-016）。
4. 任务运行超 30 分钟置 failed 并记录 error（REL-03）。
5. manual 运行归属当前用户、仅本人可见（REQ-015）。

【非功能需求约束 DFX】⭐

QS-004 要求 DFX 需求基线全量落地，不满足项有 Story 跟踪。

- 性能：业务查询接口（策略列表）p95 ≤1s（PERF-02，Story1.1.1）；选股提交 ≤2s（PERF-03，Story1.1.2）；高频页加载 p99 ≤3s、无 ≥7s 页（PERF-01）
- 可靠性：手动选股失败重试 3 次指数退避（REL-02，Story1.1.3）；长任务 30 分钟超时置 failed（REL-03，Story1.1.3）
- 安全性：需登录后访问、未登录重定向（SEC-02，Story1.1.1/1.1.2）；越权访问返回无权限语义（SEC-01）
- 可测试性：插件地址环境变量可配、可指向测试桩（TES-02，Story1.1.2）
- 可运维性：运行记录可追溯、配置环境变量化（LOG-02/03）
- 其他：单任务并发（SCA-02，Story1.1.3）；非 XAAS，客户成功维度不涉及（QS-008 裁剪）
