职责：服务端 `/ws/notify` 端点：连接鉴权（token）、连接按 user_id 路由、每用户独立连接不泄漏；新站内信实时推送（latest_id/title/摘要）。

2、【A/C验收条件】 - 开发者（待填写）

- 连接鉴权：无有效 token 拒绝连接；token 失效 → 断开，客户端 refresh 后重连，失败回登录。
- 按 user_id 路由：A 的消息仅 A 的连接收到，B 不受影响。
- 推送负载：latest_id/title/摘要（不含敏感信息）。
- 心跳保活；连接异常断开资源回收（每用户独立连接）。
- 非功能：在线事件→客户端 ≤5s（PERF-05）；连接不泄漏（REL-04）；端点入文档（OPN-01）。
- 验收：A/B 在线，推送 A 的消息 → 仅 A 收到；无 token 连接被拒。
