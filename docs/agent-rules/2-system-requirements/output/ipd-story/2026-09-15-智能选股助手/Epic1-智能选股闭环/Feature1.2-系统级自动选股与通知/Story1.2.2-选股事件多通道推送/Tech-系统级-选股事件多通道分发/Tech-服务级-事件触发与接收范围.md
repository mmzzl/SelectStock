1、【技术故事】 - 开发者（待填写）

系统级 Tech：Tech-系统级-选股事件多通道分发（Story1.2.2 / REQ-008）。
职责：select_completed（命中数/日期/前 N 条摘要，N 默认 5 可配置）/ select_failed（失败原因摘要）事件定义与触发接入；接收范围解析（manual→属主、system→全员）。

2、【A/C验收条件】 - 开发者（待填写）

- 触发时机与事件负载符合内容模板；N 默认 5 可配置环境变量化。
- 接收范围：manual 完成 → 通知归属用户；system 完成 → 通知全体用户。
- 事件负载仅选股元数据（code/name/signal/reason），不含认证/密钥。
- 终端幂等：同一事件重复触发不产生重复通知。
- 非功能：事件产生→站内信落库 ≤1s（PERF-07）；开放类型扩展（后续 select_*）。
- 验收：独立事件触发 → webhook payload/站内信/WS 三路一致（TES-03/04）。

- 风险：推送范围误扩散（低）→接收范围单测覆盖 manual/system 两态。
