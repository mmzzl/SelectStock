1、【技术故事】 - 开发者（待填写）

系统级 Tech：Tech-系统级-外部导入幂等管道（Story1.2.1 / REQ-005）。
职责：后端 `POST /select/import` 单一导入接口：幂等键校验、创建 system 运行落库、触发 select_completed 全员通知；导入不做选股计算。

2、【A/C验收条件】 - 开发者（待填写）

- 入参：幂等键 K + 信号集；鉴权复用统一认证，无凭据 401。
- 幂等：相同 K 不重复建 run，返回已有运行 id；格式非法返回 4xx 不产生运行。
- 产出 owner_type=system 运行 + 落库 + select_completed 触发（全员）。
- 普通用户构造 owner_type=system → 以调用者凭据判定，不信任开放字段。
- 空信号创建 result_count=0 的运行（留痕）。
- 非功能：500 条信号导入 ≤5s（PERF-06）；幂等、失败可重试无脏数据（REL-06）。
- 验收：固定 K 连调 3 次 → select_runs 仅 1 条、明细不重复。
