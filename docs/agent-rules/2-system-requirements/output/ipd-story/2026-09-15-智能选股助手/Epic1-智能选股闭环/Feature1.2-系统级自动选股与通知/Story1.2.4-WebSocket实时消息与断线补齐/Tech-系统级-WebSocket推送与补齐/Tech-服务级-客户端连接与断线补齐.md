系统级 Tech：Tech-系统级-WebSocket推送与补齐（Story1.2.4 / REQ-010）。
职责：客户端连接管理：登录态连 WS、心跳保活、自动重连（指数退避/后台节流）、本地 latest_id 维护、重连后按 since=latest_id 拉站内信补齐；安卓本地通知弹系统通知栏。

2、【A/C验收条件】 - 开发者（待填写）

- 本地维护 latest_id；重连成功后请求 since=latest_id 补齐缺口（不回 id 本身），无漏无重。
- 心跳超时 → 断开重连（指数退避；后台节流），回前台立即恢复同步。
- token 失效 → 刷新 token 重连，失败回登录。
- 安卓：推送到达/站内信新增 → 本地通知弹系统通知栏（买入/卖出信号）。
- 非功能：在线事件→客户端 ≤5s（PERF-05）；断线期间消息不丢（站内信为同步源）。
- 验收：断线期间产生 3 条站内信 → 重连补齐 3 条 latest_id 收敛。

3、【依赖与风险】 - 开发者（待填写）

- 依赖：WS 端点（REQ-010）、站内信接口（REQ-009）、认证（REQ-011）。
- 风险：重连时序边界（中）→latest_id 幂等语义单测覆盖。
