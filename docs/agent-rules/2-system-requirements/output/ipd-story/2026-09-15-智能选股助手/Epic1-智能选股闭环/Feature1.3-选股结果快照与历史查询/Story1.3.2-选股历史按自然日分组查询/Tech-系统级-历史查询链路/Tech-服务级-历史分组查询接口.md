2、【A/C验收条件】 - 开发者（待填写）

- 自然日分组以 started_at 截断；同一分组内按时间倒序。
- 分页 ≤50/页、无漏无重；空历史 → 空态数据。
- 强制用户作用域过滤（REQ-015）；B 访问 A 的 manual 运行 → 无权限语义。

- 验收：构造 N 天 M 次运行 → 分组数/运行数/字段正确；跨用户越权被拒。
