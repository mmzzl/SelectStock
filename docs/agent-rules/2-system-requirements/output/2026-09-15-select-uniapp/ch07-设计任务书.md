## 7.2 模块整体目标

### 7.2.1 性能目标

| 指标项 | 目标值 | 自检 |
|---|---|---|
| 高频页面加载（选股/结果/消息 Tab） | p99 ≤ 3s，无 ≥7s 页面，参见 §4.1 PERF-01 | |
| 业务查询接口（策略列表/历史/站内信） | p95 ≤ 1s，参见 §4.1 PERF-02 | |
| 选股执行提交响应 | ≤ 2s 返回 run_id，参见 §4.1 PERF-03 | |
| 选股任务完成时限 | 30 分钟内完成并落库，参见 §4.1 PERF-04 | |
| 在线消息推送延迟 | 事件→客户端 ≤ 5s，参见 §4.1 PERF-05 | |
| 外部导入吞吐 | 500 条信号 ≤ 5s，参见 §4.1 PERF-06 | |
| 站内信落库延迟 | 事件→站内信落库 ≤ 1s，参见 §4.1 PERF-07 | |

> 性能指标包括但不限于：并发用户数、响应时间、吞吐量、CPU 使用率、内存使用率等，目标值引用自 §4.1。

## 7.4 模块范围划分（边界约束提示）

| 模块 | 目标/范围 | 关键不涉及 |
|---|---|---|
| 客户端（UniApp） | 4 Tab 响应式外壳、登录/改密/登出、选股交互、历史浏览、站内信、渠道/策略、版本升级 | K 线、自选股、持仓、RBAC 页 |
| 后端 select 模块 | 策略代理、立即选股异步、历史查询、导入（幂等）、快照落库 | 不内嵌选股计算、不内嵌调度 |
| 后端 notify/消息 | 渠道/策略复用、select_* 事件、站内信、WS 推送 | 不引入 UniPush/厂商通道 |
| 后端版本模块 | 版本检查、APK 托管目录、版本记录管理 | iOS 分发、wgt 热更新 |
| 外部调度服务 | 定时调插件 + 调用 `POST /select/import` | 不在 FastAPI 内实现 |
