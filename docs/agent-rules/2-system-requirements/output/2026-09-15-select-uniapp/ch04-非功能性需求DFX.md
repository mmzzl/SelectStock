# 4. 非功能性需求（DFX）

> 以下均为量化指标；未含在 TR1 或本节裁剪说明的维度以"裁剪说明"记录。约束语级：必须/应当/可以/暂不。

## 4.1 性能（Performance）

> 指标来源：PERF-01~04 用户已确认（TR1 §2.2.1）；PERF-05~07 为用户在 TR1 复评后确认的补充量化指标，已入本文件并记录于 ch09 修订记录。

| 编号 | 指标 | 目标值 | 约束语级 | 补充说明 |
|---|---|---|---|---|
| PERF-01 | 高频页面加载（选股/结果/消息 Tab） | p99 ≤ 3s | 必须 | 无 ≥7s 页面；低频页面流畅占比 ≥90% |
| PERF-02 | 业务查询接口（策略列表/历史/站内信） | p95 ≤ 1s | 必须 | 覆盖 REQ-001/004/009 |
| PERF-03 | 选股执行提交响应 | ≤ 2s 返回 run_id | 必须 | 异步长任务不计入；REQ-002 |
| PERF-04 | 选股任务完成时限 | 30 分钟内完成并落库 | 必须 | 超时兜底置 failed（REQ-016） |
| PERF-05 | 在线消息推送延迟 | 事件→客户端 ≤ 5s | 必须 | WebSocket 在线场景（REQ-010） |
| PERF-06 | 外部导入吞吐 | 500 条信号 ≤ 5s | 应当 | REQ-005 |
| PERF-07 | 站内信落库延迟 | 事件产生→站内信落库 ≤ 1s | 应当 | REQ-008 |
| PERF-08 | 持仓诊断完成时限 | 30 分钟内完成判定+快照落库 | 应当 | 超时兜底 failed + portfolio_diag_failed（REQ-019） |
| PERF-08 | 持仓诊断完成时限 | 30 分钟内完成判定并落库 | 必须 | 超时兜底置 failed + portfolio_diag_failed（REQ-019） |

**裁剪说明：** 不含压测容量、并发峰值基线（个人工具、个位数账号低并发）。

## 4.2 可靠性（Reliability）

| 编号 | 指标 | 目标值 | 约束语级 | 补充说明 |
|---|---|---|---|---|
| REL-01 | SLA | 无对外 SLA（记录裁剪） | 暂不 | 单节点部署，无集群/RTO/RPO/过载熔断 |
| REL-02 | 手动选股失败重试 | 3 次指数退避（含抖动） | 必须 | 仍失败置 failed + select_failed |
| REL-03 | 长任务超时兜底 | 30 分钟 → failed + error | 必须 | 无僵尸任务 |
| REL-04 | 消息不丢 | 断线由站内信持久化补齐 | 必须 | since=latest_id（REQ-010） |
| REL-05 | 破坏性操作二次确认 | 删除渠道等须二次确认 | 必须 | REQ-006 |
| REL-06 | 幂等导入 | 重复导入不重复建 run | 必须 | REQ-005 |
| REL-07 | 持仓诊断插件不可用重试 | 插件不可用重试 3 次指数退避（含抖动） | 必须 | 仍失败置 failed + portfolio_diag_failed（REQ-019） |
| REL-08 | 持仓诊断批次幂等重放 | 相同批次幂等键重入不重复建 run/判定 | 必须 | REQ-019 |

**裁剪说明：** 无集群容灾、无跨机房、无数据备份体系（沿用既有部署脚本的数据库快照实践，见 §4.6）。

## 4.3 可用性（Availability）

| 编号 | 指标 | 目标值 | 约束语级 | 补充说明 |
|---|---|---|---|---|
| AVA-01 | 服务可用性 | 无对外可用性承诺（记录裁剪） | 暂不 | 个人工具；健康检查供外部监控 |

**支撑功能：** 健康检查 `GET /api/health` 供外部调度/监控探测。

## 4.4 安全（Security）⭐必须

| 编号 | 指标 | 目标值 | 约束语级 | 补充说明 |
|---|---|---|---|---|
| SEC-01 | 多账号数据隔离 | 私有数据仅属主可见，越权返回无权限语义 | 必须 | REQ-015；渠道/站内信/manual 运行 |
| SEC-02 | 认证机制 | JWT + 验证码 + 失败锁定 + 密码到期网关 | 必须 | 复用既有认证（REQ-011） |
| SEC-03 | 渠道密钥存储 | AES-GCM 加密落盘，不明文返回 | 必须 | 沿用 notify_service |
| SEC-04 | 版本安装包完整性 | 下载后校验 MD5，不一致拒绝安装 | 必须 | REQ-014 |
| SEC-05 | 写操作审计 | 渠道/策略/版本/登录写留痕 | 必须 | REQ-017 |
| SEC-06 | 部署密钥 | JWT_SECRET 等隔离子进程 env | 必须 | .env 联邦（非硬编码/非明文入库） |
| SEC-07 | 认证令牌 | 不写日志、登录态不定时过期、过期回登录 | 必须 | REQ-011/013 |
| SEC-08 | 第三方依赖安全 | 版本锁定（requirements 锁/package-lock）+ 依赖漏洞扫描（pip-audit / npm audit）；上游安全公告后评估升级并随版本发布登记 ch09 | 必须 | 覆盖 UniApp SDK/FastAPI/选股插件等 |

**裁剪说明：** 无签名/验签、无异地登录检测、无 RBAC 页面（账号由 sys_users 供给，本期复用既有鉴权）。

## 4.10 DFX 术语与度量方法

| 术语 | 定义/度量方式 |
|---|---|
| p95/p99 | 接口响应时间第 95/99 百分位，从 HTTP 进入→响应输出计算 |
| 节流间隔 | 同一事件+渠道的发送时间窗，窗口内合并/跳过（REQ-007） |
| 越权返回无权限语义 | 403/404 等价响应，不泄露资源存在性（REQ-015） |
| 指数退避 | 重试间隔 2^n * base + 抖动，默认最大 3 次（REQ-016） |
