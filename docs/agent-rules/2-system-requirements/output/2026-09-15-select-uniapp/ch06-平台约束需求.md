# 6. 平台约束需求

## 6.1 产品能力边界

| 类别 | 约束内容 | 约束语级 | 关联需求 |
|---|---|---|---|
| 选股流程 | 后端不内嵌/不重写任何选股计算，只代理查询插件信号并落库 | 必须 | REQ-001/002/005 |
| 选股流程 | 后端不内嵌任意持仓买卖判定与收益计算，判定收敛到插件 `POST /api/portfolio/analyze`，收益以插件返回为准 | 必须 | REQ-019 |
| 选股流程 | 定时任务不进 FastAPI，由外部独立调度服务驱动导入（选股与持仓诊断共用） | 必须 | REQ-005/019 |
| 选股流程 | 同一时刻全局仅 1 个运行中任务（选股/持仓诊断共用并发位） | 必须 | REQ-016 |
| 选股流程 | manual 运行归属用户、scheduled/system 运行全员可见；持仓与持仓诊断仅属主可见（无全员语义） | 必须 | REQ-015 |
| 范围边界 | 客户端范围 = 选股/结果/消息/设置 4 Tab + 持仓管理（含持仓录入/导入、诊断历史回看），不含 K 线/自选股/RBAC 管理页 | 必须 | REQ-012 |
| 范围边界 | 注册/密码找回不在客户端范围（账号由 sys_users 供给） | 必须 | REQ-011 |
| 通知 | 不引入 UniPush/个推厂商通道，App 被杀后不承诺离线送达 | 必须 | REQ-010 |
| 通知 | 消息双路：外部渠道 by 策略 + 站内信必写 | 必须 | REQ-008 |
| 版本 | iOS 原生分发与 wgt 热更新不在本期 | 必须 | REQ-014 |

## 6.2 开发规范约束

| 类别 | 约束内容 | 约束语级 | 关联需求 |
|---|---|---|---|
| 复用 | 通知必须复用既有 notify_service（渠道/策略/加密/节流） | 必须 | REQ-006/007 |
| 复用 | 认证必须复用既有 auth 链路（JWT/验证码/锁定/到期） | 必须 | REQ-011/013 |
| 搭建 | 客户端使用 UniApp 一套代码多端编译（H5 + App） | 必须 | REQ-012 |
| 架构 | 前端不承重隔离（越权防护为服务端强制规则） | 必须 | REQ-015 |
| 异步 | 选股/持仓诊断执行为异步，前后端不做阻塞轮询 | 必须 | REQ-002/019/016 |
| 幂等 | 导入接口必须幂等（选股导入 REQ-005；持仓诊断入口按批次可重放可鉴权） | 必须 | REQ-005/019 |
| 令牌 | token 不入日志、不明文存储 | 必须 | REQ-011 |

## 6.3 共性功能约束

| 类别 | 约束内容 | 约束语级 | 关联需求 |
|---|---|---|---|
| 登录态 | 全部业务页必须经路由守卫；未登录重定向登录页 | 必须 | REQ-012 |
| 会话 | 401 统一拦截 + refresh 自动续期，失败回登录 | 必须 | REQ-011 |
| 确认 | 删除渠道等破坏性操作必须二次确认 | 必须 | REQ-006 |
| 加载 | 高频页无 ≥7s 页面 | 必须 | PERF-01 |
| 空态 | 列表类页面（策略/历史/消息/渠道）必须有空态与引导 | 必须 | REQ-001/004/009/006 |
| 错误 | 依赖不可用展示可读提示，不崩溃 | 必须 | REQ-001 |
| 审计 | 写操作留痕 | 必须 | REQ-017 |

## 6.4 环境约束

| 类别 | 约束内容 | 约束语级 | 关联需求 |
|---|---|---|---|
| 后端环境 | Linux + systemd 部署（沿用 deploy/） | 必须 | 部署 |
| 配置 | SELECT_PLUGIN_URL/并发/超时/节流等环境变量化 | 必须 | 部署 |
| 插件地址 | 插件地址可配，可指向测试桩 | 必须 | TES-02 |
| H5 浏览器 | Chrome 80+/Edge 79+/Safari 13.1+/FF 72+ | 必须 | COM-02 |
| Android | 安装未知应用授权引导 | 必须 | COM-04 |
| 规模 | 单节点、个位数账号、低并发 | 必须 | 总体约束 |
