## 高密度摘要

**本版本需求范围：** 为独立选股插件提供 UniApp 客户端（手机/PC 响应式）与统一后端模块：选股信号查询与快照落库、定时选股自动通知、通知渠道/订阅策略配置、站内信与 WebSocket 实时消息、多账号隔离鉴权、App 整包版本管理、**持仓诊断闭环（持仓录入/导入 → 定时发插件统一判定买卖·加仓 → 收益快照落库 → 属主通知）**。

**需求总览：**
- 功能性需求：共 **21** 个（P0: **19** / P1: **2**）——REQ-001~REQ-021，其中 REQ-018~021 为 V1.1 新增 `[持仓诊断]`
- 测试点：TC ×21 / PT ×5 / RT ×5 / ST ×8 / CT ×2

**全局强约束（必须遵守，适用于全部章节）：**
- **必须**：所有章节不得为空；如不涉及须说明原因
- **必须**：所有需求须有唯一编号（REQ-XXX 格式）
- **必须**：所有指标须量化（禁止"合理""适当""性能较好"等模糊表述）
- **必须**：验收条件须为可客观判断的描述（✅/❌ 可判定）
- **禁止**：在本文档中描述技术实现方案

**不在本次范围内：** k 线图、自选股/关注列表、UniApp 内用户/角色/RBAC 管理页、注册与密码找回、iOS 原生分发与 wgt 热更新、UniPush/个推厂商离线推送、出海国际化、NFV/XAAS、数据自动清理。持仓诊断涉及买卖/加仓判定与收益计算，**判定完全收敛到插件**（后端零计算），新买入候选由选股信号产出。

**术语速查（详见 ch01 §1.2）：** 选股插件 / SelectRun / SelectResult / Channel / Policy / Inbox / 外部调度服务 / manual·system 运行 / latest_id / version_code / force / Holding / DiagRun / DiagResult / 收益快照
