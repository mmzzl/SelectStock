# 2026-09-20 App 部署说明（backend / 插件 / 客户端）

## 服务启动
- backend(8000): `cd stock_selector_api/backend && python -m uvicorn main:app --port 8000`
- plugin 持仓诊断(8001): `cd stock_selector_api/plugin && python -m uvicorn server:app --port 8001`
- selector 选股(8002): `bash scripts/start_selector.sh`
- scheduler：**随 backend 进程内启动**（main.py lifespan 读取 `backend/conf/inputs.conf` 注册任务，无需独立进程）

## 首次初始化
- SQLite 自动建表（`stock_selector_api/backend/data/app.db`，WAL）；老库 holdings 自动补列
- 建管理员与普通用户；RBAC 权限由既有 seed 配置

## H5 发布流程
1. `npm run build:h5`（uniapp/）
2. 上传制品到静态服务器
3. 管理端 `POST /api/v1/upgrade/packages`（platform=h5，新 version_code 严格递增，is_published=true）
- 客户端启动即查 `/api/app/latest?platform=h5`，提示「版本更新→刷新」

## App 发布（wgt 热更 / 整包）
1. `npm run build:app` → HBuilderX 制作 wgt 或云打包 apk/ipa
2. 管理端「上传」得到 url+md5+size
3. 建 upgrade_packages（platform=android|ios，package_type，version_code 严格递增，forced 可设）
4. 客户端 `/api/app/latest` 比对 version_code 触发更新；forced=true 时弹窗不可跳过；iOS 原则上仅发布 wgt

## 定时任务（conf/inputs.conf）
- `[task://market_daily:daily_diag]` 每日 18:00（全用户盘后诊断，完成后站内信通知）
- `[task://market_daily:daily_selection]` 每日 17:30
- 时间可直接改 conf 后重启 backend 生效

## 升级中心说明
- 自托管等价 uni-upgrade-center：后端 `upgrade_packages` 表 + 公开 `/api/app/latest`、`/api/app/version`；不依赖 uniCloud
- 上传目录 `settings.upgrade_upload_dir`（静态挂载于 `/uploads/upgrade/...`）

## 端口与代理
- backend 8000 / plugin 8001 / selector 8002
- uniapp dev 代理：vite 将 `/api`、`/ws` 转发到 8000
- 全市场选股较重：手动触发为 job+轮询（`/api/v1/selection/runs/{job_id}`，客户端每 2s），单飞由后端保证
