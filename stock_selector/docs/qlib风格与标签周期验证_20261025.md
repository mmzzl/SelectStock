## 批次 O：Alpha158 + 风格/残余因子（`so_` 9 列）

### 预注册（训练前写定）

- 特征清单（`stock_selector_qlib/alpha_style.py`，训练/打分共用一个类；最长窗口 60 日）：
  `so_rsi14, so_macd_dif, so_macd_hist, so_retvol20, so_skew20, so_kdj60, so_amihud20,
  so_overnight, so_intraday`。
- 明确不加：动量/ROC、价格水平 STD、高低差（KLEN）——Alpha158 已有；市值 Size、Beta、
  价值/盈利/成长/杠杆——面板表达式算不了（Beta 要跨票对指数回归、基本面要财报数据链），
  留给以后的单列数据批。
- 判定（沿用手册两臂配对纪律）：同池冻结（`model_live2026jun/pool.txt`）、同种子
  `--seed 7`、同树 `--fixed-trees 141`、同特征外的唯一差异 = 特征集
  （`--feature-set base→style`），三窗双臂配对：
  - W2024H2：train_end 2024-06-30，留出 2024-07-01→12-31
  - W2025H2：train_end 2025-06-30，留出 2025-07-01→12-31
  - 2026 当前窗：train_end 2026-06-30，留出 2026-07-01→10-16（与批次 M 同段）
- 换线门槛：全段配对 t（÷√5 四滞后调整）≥ 2（保留批次 M 口径），**多窗为手段不是门槛**。

## 批次 P：标签周期（t+1→t+5 改 t+10 / t+20 判分）

### 为什么试

同一甜点组合是**慢换手的 band 持有型**（top20 买入、跌出前 300 才卖、风险度截仓），
而 live 模型在优化一个 5 日目标：信号周期与持有节奏不匹配。批次 P 就是把训练目标换成
**t+1 买 → t+10 / t+20 收盘卖**（`LABEL_FMT` 的 h 参数化，`scripts/qlib_run.py
--label-horizon`，批次 P 预注册声明过「改了它 = 改训练目标，与历史 IC 读数不可直接比」）。

### 判定器（本批专设，与批次 O 不同）

- IC 配对**不可用**（两臂测的不是同一个标签），主判定 = **同一回测器、同池、同甜点参数
  的三窗组合读数**（区间收益/超额/回撤/换手四项）。
- 每窗双臂：h5 臂（base 特征、h5 标签）vs h10/h20 臂（base 特征、同窗新标签）。
  2024/2025 窗的 h5 臂 = 批次 O 的 base 臂（同窗同种子同树，批次 O 已训好，直接复用 pred）。
- 诚实声明：这个判定器是**本批立项时与训练代码一起写下的**（`--label-horizon` 帮助文本
  与本节），但三窗的具体数字写读数前未预设任何值；换线与否除了下表，还必须过
  「全市场复检 + 影子盘」，两级都过才算换。

### 读数（池 300 冻结，甜点 t20/r0.35/e300，成本基准档）

| 窗 | 周期 | 区间 | 超额(年化) | 回撤 | 换手/日 |
|---|---|---:|---:|---:|---:|
| 2026-07-01→10-16 | h5 | −5.46% | +26.36% | **−9.71%** | 0.80% |
| | h10 | −4.57% | +29.03% | −7.04% | 0.48% |
| | **h20** | **−3.35%** | **+32.75%** | **−6.60%** | 0.48% |
| 2024H2 | h5 | +5.55% | −20.91% | −3.97% | 0.28% |
| | h10 | +5.27% | −21.48% | −3.90% | 0.28% |
| | **h20** | **+8.53%** | **−14.74%** | −4.22% | 0.28% |
| 2025H2 | h5 | +0.80% | −39.14% | **−3.05%** | 0.28% |
| | h10 | +13.27% | −13.51% | −3.78% | 0.28% |
| | **h20** | **+17.85%** | **−3.41%** | −4.66% | 0.28% |

（2024/2025 窗的超额项负值是因为那两段 300 ETF 大涨把基准线拉高，属基准相对读数；
**臂间对比仍是同基准同池，有效**。）

### 判定与候选

- 换手：h10/h20 都把 2026 当窗换手从 0.80% 砍到 0.48%/日，**成本结构改善是真且可复制的**。
- 区间收益：h20 三窗全胜；h10 两胜一平。
- 回撤：h10 三窗全最小；h20 两窗第二、2025H2 比 h5 深 1.6pp。
- **候选顺序：h10（均衡/回撤最优）> h20（收益上限最高）**。要「收益更高、回撤更小」
  的诉求，h10/h20 都比 live（h5）好；h20 再往上一档但 2025 窗回撤信号说明 holdings
  周期变长后尾部风险也变长，不宜直接当默认。

### 换线门槛（批次 P 正式条文，过全过才换默认线上模型）

1. **全市场复检**：候选（h10 或 h20）在全市场 universe 面板上重打 2026-07→10 分数，
   以甜点组合跑同窗回测，四项读数（区间/超额/回撤/换手）**全部不劣于 live h5 的全市场
   读数**；且 exit_rank ∈ {200,300} 与 risk_degree ∈ {0.35,0.5} 的四格小对照不出现
   崩档（防止 5 日信号调的参数对 10/20 日信号水土不服）。
2. **影子盘 3-6 个月**：h10 做主影子组合，h20 与 live h5 同框架各挂一路对照影子
   （纸面零成本，三个并行）。
3. 影子盘无门槛违反 → 换默认模型并全链回归（8003/入口/回测缺省）。
4. 批次 O 的 so_ 特征**不参与**本次换线（保持单变量），以后另立批次再议。
