# qlib 全市场：-8% 止损 / +10% 止盈验证（预注册）

日期：2026-10-25。先写规则，再读新臂结果，避免看到回撤改善才改口径。

## 问题

现有全市场动态票池、`topk=1`、band 50/100 的样本外结果：

| 臂 | 年化 | 超额 | 最大回撤 | 日换手 | 年成本 |
|---|---:|---:|---:|---:|---:|
| 基准成本 | +17.53% | +11.59pp | -53.64% | 28.39% | 6.89% |
| 滑点压力 | +9.72% | +3.77pp | -54.80% | 28.39% | 13.79% |

加一条「相对买入价下跌 8% 卖出、上涨 10% 卖出」，是否能把最大回撤解决？

## 口径

- 其余不变：同一模型、同一窗口 `2024-01-02 → 2026-10-22`、同一动态每日票池、同一 band 50/100、同一成本/滑点压力、同一基准 `SH510300`。
- 买入价 = 实际成交价（T 日收盘）。持仓从下一交易日起才检查，符合 A 股 T+1。
- 每个交易日 T 用 T 日收盘价相对买入价判断；触发后按同一个 T 日收盘价卖出。
- 这是**日频近似**：同一收盘成交偏乐观，但只看收盘触发会漏掉盘中破位；跳空、跌停卖不掉、卖出后当天又买回等都没有建模，净偏差方向不定，不能当实盘止损价。
- 卖出后释放的仓位按原 band 规则补下一只；不因为止损/止盈改变选股分数。
- 主臂 `st_top1`（剔现名 ST/退），对照 `st_top10`；另跑 `all` 敏感性。基准成本和滑点压力都跑。

## 裁决门槛（主臂）

「解决」必须同时满足：

1. `topk=1` 基准成本和滑点压力的年化超额都 > 0；
2. 最大回撤比无止损基线（-53.64% / -54.80%）至少改善 10pp；
3. 最大回撤不差于 -30%；
4. 近一年超额 > 0；
5. 2024/2025/2026 至少 2 年超额 > 0。

只满足 1、2、4、5 但回撤仍差于 -30%：记为「缓解，不算解决」。
连这套日频近似都过不了 1/2：直接判定这条规则救不了单票回撤，不拿它给实盘背书。

## 分解臂（读合并臂之前追加）

合并臂若回撤没改善，不能直接说「止损没用」还是「止盈拖累」。再跑两条同口径分解臂：

- `sl8`：只开 -8% 止损，止盈关闭；
- `tp10`：只开 +10% 止盈，止损关闭。

两条都只跑 `topk=1` 基准/压力、`topk=10` 基准/压力、`all` 基准；裁决门槛同上。
主结论仍看合并臂和 `sl8`，`tp10` 只用来解释收益/回撤来源。

## 结果（2026-10-25 跑完）

`topk=1` 主臂，基准成本 / 滑点压力：

| 臂 | 年化 | 超额 | 最大回撤 | 日换手 | 年成本 | 卖出 |
|---|---:|---:|---:|---:|---:|---:|
| 无止损（原基线） | +17.53% / +9.72% | +11.59 / +3.77pp | -53.64% / -54.80% | 28.39% | 6.89% / 13.79% | 111 |
| 只开 -8% 止损 | +12.61% / +3.97% | +6.66 / **-1.98pp** | **-69.78% / -71.14%** | 32.61% | 7.91% / 15.84% | 127 |
| 只开 +10% 止盈 | +25.00% / +16.21% | +19.05 / +10.26pp | **-48.95% / -50.18%** | 30.26% | 7.35% / 14.71% | 116 |
| -8% 止损 + +10% 止盈 | +24.19% / +13.88% | +18.24 / +7.94pp | **-62.21% / -65.19%** | 35.72% | 8.68% / 17.36% | 136 |

分年超额（基准成本，2024 / 2025 / 2026）：

- 无止损：-39.4 / +23.9 / +43.9pp
- 只开 -8%：**-75.3** / +101.3 / +70.9pp
- 只开 +10%：-35.9 / +34.4 / +51.6pp
- 合并：**-70.0** / +117.3 / +82.5pp

2024 年策略自身收益：无止损 -22.9%，只开止损 -58.9%，只开止盈 -19.4%，合并 -53.6%。
最大回撤的峰谷都在 2024 年（基线 2024-02-27 → 2024-09-19；只开止损 2024-01-02 → 2024-09-24），
所以这不是「回撤发生在别处、止损没赶上」，而是止损在 2024 年自己打出来的。

`topk=10` 对照：合并臂基准成本回撤 -32.41%（原 -32.44%），压力 -36.80%（原 -33.52%）；只开止损回撤 -35.81% / -38.26%，只开止盈 -32.33% / -35.65%。止损同样没有改善回撤。

## 裁决

**没有解决，反而更差。**

- 合并臂回撤比原基线恶化 8.6pp / 10.4pp，不满足「改善 10pp」和「不差于 -30%」两条，直接判不通过。
- 分解后责任很清楚：**-8% 止损是拖累**。只开止损时，基准成本回撤 -69.78%，2024 年超额 -75.3pp；滑点压力下年化超额变成 -1.98pp。8% 止损在单票高波动策略里反复实现亏损、再买回高波动票，2024 年震荡市被来回打。
- **+10% 止盈单独看略有帮助**：回撤 -53.64% → -48.95%，压力 -54.80% → -50.18%，但只改善 4~5pp，仍远差于 -30%，只能算「缓解，不算解决」。而且它把上涨截断在 +10%，收益并没有比原基线差太多，是三条里唯一没明显变坏的。
- 合并臂收益看起来更高（年化 +24.19%），但这是拿更大的回撤和更高换手换来的；2024 年超额 -70pp，不能当改进。
- 以上是**同一收盘价判断、同一收盘价成交**的日频近似；盘中破位、跳空、跌停卖不掉、T+1 真实成交都没有建模，净偏差方向不定。但在这套近似下，止损仍把回撤从 -53.6% 拉到 -69.8%，没有理由拿它给实盘背书。

结论：不要把这组 -8%/+10% 直接加到线上。若还要试，下一步应只试「更宽的止损（如 -15%）」或「止损后冷却 N 天不买回」，并且仍按同样门槛先回测；当前不做。
