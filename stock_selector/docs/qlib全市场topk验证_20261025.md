# 全市场动态票池 · topk=1 / topk=10 验证（2026-10-25 预注册）

**这份文件写在任何回测读数之前。** 目的不是再找一个「看起来能赚」的参数，而是回答一个更窄的问题：

> 线上这套模型（`batchQ_lab10`，训练截止 2023-12-31）放到**每日动态全市场票池**上，
> 按线上两条护栏过滤后，只买最高分一只（`topk=1`）或买前十只（`topk=10`），
> 扣掉成本、滑点压力、涨跌停挡单后，2024-01-02 起的样本外窗口里能不能跑赢 `SH510300`？

**不调参、不换模型、不换标签、不换窗口。** 读完数后不许把某一条线挪到「刚好过」。
这份验证不授权实盘；即使全过，也还要 3~6 个月影子盘。

## 1. 口径

| 项 | 取值 |
|---|---|
| 模型 | `data/qlib/model`，`batchQ_lab10`，`train_end=2023-12-31`，158 因子 |
| 主窗口 | 2024-01-02 → 2026-10-22（模型训练截止之后的样本外；10-23 面板末行不完整，不参与撮合） |
| 子窗口 | 2025-10-23 → 2026-10-22（近一年，路径依赖，仅作读数） |
| 基准 | `SH510300` |
| 票池 | 每日动态：A 股（sh.60 / sh.68 / sz.00 / sz.30），上市满 130 根日线，过去 20 个交易日日均成交额 ≥ 1 亿元；剔除 2026-10-18 现名 ST/退清单（113 只） |
| 退市/停牌 | 票池按当日是否有收盘价判定；退市/停牌票从当日名单消失，持仓按 qlib 撮合规则处理 |
| 护栏 | 线上同源两条：20 日均额低于当日打分票池 P25 的「薄流动」；拉升后回撤 ≥20% 但近 20 日跌幅 <15% 的「拉升后阴跌」 |
| 纪律 | band：进榜前 50、出榜前 100；`topk=1` 和 `topk=10` 各跑一臂；买入时等权，不每日再平衡 |
| 成交 | T 日收盘成交，读 T−1 分数；先卖后买；涨跌停/停牌挡单；9.5% 统一挡单（20% 板也挡，偏严） |
| 基准成本 | 买 5bp、卖 15bp、最低 5 元 |
| 滑点压力 | 买 15bp、卖 25bp（在基准成本上每边加 10bp，作为压力读数；不是精确冲击模型） |

**已知残余偏差（必须一起读）：**

1. ST 剔除用的是 2026-10-18 的现名清单，不是历史 ST 标记。对 2024 年以前已经摘帽的票会误剔，对 2024 年后才戴帽的票会漏剔；这是**前视/幸存者偏差**，不是可实盘的历史判据。
2. 票池的「上市满 130 根、20 日均额 ≥1 亿」是按当日及以前行情算的，不用未来数据；但 qlib bin 面板是否完整覆盖已退市票，仍取决于导出链。
3. 滑点压力只是把费率加上去，没有模拟冲击成本、盘口深度、成交量占比。
4. 9.5% 统一挡单会把创业板/科创板 20% 的票也挡掉，偏严；不会美化收益。
5. 票池每日按 1 亿门槛变化，2024 年低流动性时段票池只有约 1,300~2,200 只，2026 年约 2,800~3,900 只；这是策略真实面对的可交易域，不是固定 300 只。

## 2. 仪器门（先过，才看收益）

1. 净值曲线起点 = 初始资金，终点 = `metrics.end_value`（差 < 1 元）。
2. 有换手时 `gross_return ≥ total_return`（成本真的进了净值）。
3. `cost_annualized / (单边换手 × (买费率+卖费率) × 243)` 落在 `[0.5, 1.5]`。
4. `trade_count > 0`，且 `topk=1` 的持仓只数不超过 1。

任何一条不过：读数作废，先修仪器。

## 3. 裁决线

主臂 A = `topk=1`，基准成本，动态票池（剔 ST），护栏开。  
对照臂 B = `topk=10`，同池同护栏同成本。

A 必须同时满足：

- A1 全窗口**扣成本年化超额 > 0**；
- A2 滑点压力下**扣成本年化超额 > 0**；
- A3 近一年（2025-10-23→2026-10-22）扣成本超额 > 0；
- A4 2024 / 2025 / 2026 三个自然年里，至少 2 年扣成本超额 > 0；
- A5 最大回撤、换手、年成本、卖出笔数、胜率、盈亏比全部报告（不设门槛，但不许只报收益）。

B 同时满足 B1~B4（同 A1~A4，基准成本；B 的滑点压力只报告，不设硬门）。

**判定：**

- A 全过且 B 全过 → 「两臂都过线」；仍需影子盘，不直接实盘。
- A 过、B 不过 → 「单票臂过线，列表臂不过」；不能拿列表给单票背书，仍需影子盘。
- A 不过 → 「未证明」；不论 B 如何，不实盘。
- 统计显著性：报告日净超额 t 值；t < 2 时只写「点估计为正、显著性不足」，不许写成「有效」。

## 4. 敏感性（只报告，不参与裁决）

- `topk=1` / `topk=10`，**不剔 ST** 的动态票池，基准成本。
- 用来判断「ST 剔除」是否把结论翻了个面；不因为敏感性好看就改主臂。

**裁决：按预注册门槛，`topk=1` 与 `topk=10` 都过线；但只能进入影子盘，不直接实盘。**

必须一起读的限制：

- 两条臂的全窗日超额 t 都 < 2（0.70 / 1.91），只能说「点估计为正、显著性不足」，不能写成「有效」。
- `topk=1` 最大回撤 -53.64%，2024 年超额 -39.4pp；收益集中在 2025–2026，路径依赖很重。
- `topk=10` 的 2026 年基准超额只有 +1.0pp，压力成本下近一年超额 -0.8pp；列表臂的稳健性也不够。
- 本验证仍有 ST 现名清单的前视/幸存者偏差、9.5% 统一挡单偏严、无冲击成本/盘口深度；这些都不会让实盘更轻松。
- 2026-10-25 另测的「-8% 止损 / +10% 止盈」没有解决回撤，反而更差，见 `qlib止盈止损验证_20261025.md`；不并入本裁决。
